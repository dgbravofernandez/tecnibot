# Mantenimiento Semanal — Todas las Marcas

**Tiempo estimado:** 15-20 minutos  
**Sin necesidad de herramientas especiales**  
**Puede hacerlo el operador, no requiere técnico**

## Checklist Semanal

### Exterior
- [ ] Limpiar cristal frontal con producto no abrasivo
- [ ] Revisar que la puerta cierra correctamente y sella bien
- [ ] Comprobar iluminación interior (cambiar tubo/LED si falla)
- [ ] Verificar que no hay daños físicos visibles

### Bandeja de producto
- [ ] Retirar producto caducado o dañado
- [ ] Verificar que las espirales giran correctamente (test manual)
- [ ] Limpiar bandejas con paño húmedo (sin productos abrasivos)

### Sistema de pago
- [ ] Limpiar ranura de monedas con aire comprimido
- [ ] Verificar que el cambio está bien surtido
- [ ] Comprobar que el lector de billetes acepta correctamente

### Revisión visual de temperatura
- [ ] Confirmar temperatura en display (debe ser 4-8°C para frescos)
- [ ] Si no hay display: comprobar que los productos están fríos al tacto

## Señales de alerta que requieren acción inmediata

- Temperatura > 10°C sostenida → revisar refrigeración
- Espiral atascada → no forzar, revisar manualmente
- Billete/moneda atascada → usar protocolo de extracción del manual
- Ruido inusual → anotar tipo (zumbido, golpe, pitido) y reportar
