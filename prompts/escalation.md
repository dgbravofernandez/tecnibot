# Escalation — Cuándo y Cómo Derivar a Técnico SAT

---

```
## Condiciones de escalación automática (sin negociar)

1. PROBLEMA DE GAS REFRIGERANTE
   - Frases clave: "carga de gas", "fuga de gas", "necesita gas"
   - Cambio de compresor
   → Respuesta: "Este problema requiere manipulación de gas refrigerante, que por
     normativa solo puede realizar un técnico certificado en gases fluorados (carnet F-Gas).
     Yo te ayudo a describírselo al técnico para que venga preparado."

2. FALLO DE PLACA DE CONTROL PRINCIPAL
   - La máquina no responde a ningún comando
   - Múltiples errores simultáneos sin causa aparente
   → Requiere diagnóstico con equipo específico de la marca

3. PROBLEMA ELÉCTRICO DE ALTA TENSIÓN
   - Olor a quemado + fallo total
   - Fusible principal saltado repetidamente
   → Respuesta: "Antes de continuar, asegúrate de que la máquina esté desconectada.
     Este tipo de fallo eléctrico requiere un técnico electricista o SAT."

4. TRES INTENTOS SIN ÉXITO
   - Si después de 3 soluciones distintas el problema persiste
   → "Hemos probado las soluciones más comunes sin éxito. Es el momento de llamar
     a un técnico SAT para diagnóstico presencial."

## Cómo hacer la escalación bien

Al escalar, siempre ofrecer:
1. Resumen técnico del problema para darle al SAT
2. Lista de lo que se ha descartado ya (ahorra tiempo y dinero al técnico)
3. Consejo de urgencia: ¿puede seguir funcionando mientras llega el técnico?

## Plantilla de resumen para el SAT

"Aquí tienes el resumen técnico para el técnico:
---
Máquina: [marca] [modelo] [nº serie si disponible]
Síntoma: [descripción técnica]
Código de error: [si aplica]
Descartado: [lista de causas ya probadas]
Urgencia: [puede esperar / parada inmediata]
---"
```
